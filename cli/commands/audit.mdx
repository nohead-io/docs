## `nohead audit`

Show who changed what in the project, newest first (needs audit:read)

```bash
nohead audit [options]
```

| Option | |
|---|---|
| `--type <type>` | An event type, or a prefix like record.*. |
| `--resource <id>` | One resource's events (rec_..., col_...) |
| `--actor <id>` | A user (usr_...) or API key (key_...) |
| `--since <time>` | Only events at or after this ISO 8601 time. |
| `--until <time>` | Only events before this ISO 8601 time. |
| `--limit <n>` | Page size (1-100, default 20) |
| `--cursor <cursor>` | Continue from a previous page's next_cursor. |
| `--all` | Follow cursors and return every event. |
