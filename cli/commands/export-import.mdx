## `nohead export`

Export the project's schema and records to a directory.

```bash
nohead export [options]
```

| Option | |
|---|---|
| `--output <dir>` | Directory to write (created if needed) |
| `--include-history` | Also export every record's revisions. |
| `--include-deleted` | Also export deleted records. |
| `--include-files` | Also download every asset's original file. |

## `nohead import`

Import an export into the project: schema first, then records (re-runnable for 24 hours)

```bash
nohead import [options] <dir>
```

| Argument | |
|---|---|
| `<dir>` | A directory written by nohead export. |
