## `nohead search`

Search records: in one collection with --collection, else across the project.

```bash
nohead search [options] [query]
```

| Argument | |
|---|---|
| `[query]` | Words to search for. |

| Option | |
|---|---|
| `--collection <c>` | Search one collection (slug or ID) |
| `--filter <expression>` | Filter on a filterable field or "published_at exists", as in records list; repeatable. |
| `--sort <sort>` | created_at, updated_at, published_at or a sortable field; - for descending. |
| `--limit <n>` | Results (1-100) Default: `20`. |
