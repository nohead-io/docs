## `nohead webhooks list`

List the project's webhooks.

```bash
nohead webhooks list [options]
```

| Option | |
|---|---|
| `--limit <n>` | Page size (1-100, default 100) |
| `--cursor <cursor>` | Continue from a previous page's next_cursor. |
| `--all` | Follow cursors and return every webhook. |

## `nohead webhooks create`

Create a webhook; prints its signing secret (shown only now)

```bash
nohead webhooks create [options]
```

| Option | |
|---|---|
| `--url <url>` | Https URL to send events to. |
| `--events <types>` | comma-separated event types, or * for all. Default: `"*"`. |
| `--description <text>` | What it is for. |

## `nohead webhooks deliveries`

List a webhook's deliveries, newest first.

```bash
nohead webhooks deliveries [options] <id>
```

| Argument | |
|---|---|
| `<id>` | Webhook ID (wh_...) |

| Option | |
|---|---|
| `--status <status>` | Only deliveries with this status. One of `pending`, `succeeded`, `failed`. |
| `--limit <n>` | Page size (1-100, default 100) |
| `--cursor <cursor>` | Continue from a previous page's next_cursor. |
| `--all` | Follow cursors and return every delivery. |
