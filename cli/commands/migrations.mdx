## `nohead migrations list`

List a collection's field migrations, newest first.

```bash
nohead migrations list [options] <collection>
```

| Argument | |
|---|---|
| `<collection>` | Collection slug or ID. |

| Option | |
|---|---|
| `--limit <n>` | Page size (1-100, default 100) |
| `--cursor <cursor>` | Continue from a previous page's next_cursor. |
| `--all` | Follow cursors and return every migration. |

## `nohead migrations get`

Show a field migration.

```bash
nohead migrations get [options] <migration>
```

| Argument | |
|---|---|
| `<migration>` | Migration ID (mig_...) |

| Option | |
|---|---|
| `--wait` | Wait until it finishes. |

## `nohead migrations cancel`

Cancel a pending or running field migration.

```bash
nohead migrations cancel [options] <migration>
```

| Argument | |
|---|---|
| `<migration>` | Migration ID (mig_...) |
