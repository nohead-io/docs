## `nohead collections list`

List collections in the project.

```bash
nohead collections list [options]
```

| Option | |
|---|---|
| `--deleted` | List deleted collections instead. |
| `--limit <n>` | Page size (1-100, default 100) |
| `--cursor <cursor>` | Continue from a previous page's next_cursor. |
| `--all` | Follow cursors and return every collection. |

## `nohead collections get`

Show a collection and its fields.

```bash
nohead collections get [options] <collection>
```

| Argument | |
|---|---|
| `<collection>` | Collection slug or ID. |

## `nohead collections create`

Create a collection.

```bash
nohead collections create [options] <slug>
```

| Argument | |
|---|---|
| `<slug>` | Collection slug, e.g. posts. |

| Option | |
|---|---|
| `--name <name>` | Display name (default: from the slug) |
| `--description <text>` | description. |
| `--public-search` | Include its published records in public search (search tokens) |

## `nohead collections update`

Update a collection's name, slug, description or public search.

```bash
nohead collections update [options] <collection>
```

| Argument | |
|---|---|
| `<collection>` | Collection slug or ID. |

| Option | |
|---|---|
| `--name <name>` | New display name. |
| `--slug <slug>` | New slug (breaks clients that use the old one) |
| `--description <text>` | New description. |
| `--public-search` | Include its published records in public search (search tokens) |
| `--no-public-search` | Remove it from public search. |
