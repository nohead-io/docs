## `nohead records list`

List records (newest first by default)

```bash
nohead records list [options] <collection>
```

| Argument | |
|---|---|
| `<collection>` | Collection slug or ID. |

| Option | |
|---|---|
| `--status <status>` | Only records with this status. One of `published`, `unpublished`. |
| `--filter <expression>` | Filter, e.g. price&lt;50, released>=today, "category in shoes,bags", "cover exists", "published_at exists"; repeatable. |
| `--deleted` | List deleted records instead. |
| `--sort <sort>` | created_at, updated_at, published_at, id or a field; prefix - for descending. |
| `--expand <fields>` | Relation fields whose records to embed (comma-separated) |
| `--limit <n>` | Page size (1-100, default 100) |
| `--cursor <cursor>` | Continue from a previous page's next_cursor. |
| `--all` | Follow cursors and return every record. |

## `nohead records bulk`

Publish, unpublish, delete, restore or update many records; each gets its own revision.

```bash
nohead records bulk [options] <action> <collection> [ids...]
```

| Argument | |
|---|---|
| `<action>` | What to do to the records. One of `publish`, `unpublish`, `delete`, `restore`, `update`. |
| `<collection>` | Collection slug or ID. |
| `[ids...]` | Record IDs (or select with --status/--filter/--every) |

| Option | |
|---|---|
| `--status <status>` | Select records with this status. One of `published`, `unpublished`. |
| `--filter <expression>` | Select records by filter, as in records list; repeatable. |
| `--deleted` | Select deleted records (for restore) |
| `--every` | Select every record in the collection. |
| `--set <key=value>` | Set a field (key=text or key:=json); repeatable. |
| `--data <json>` | Record data as a JSON object. |
| `--data-file <path>` | Read record data from a JSON file (- for stdin) |

## `nohead records schedule`

```bash

```

|---|---|
