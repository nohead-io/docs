Every command takes these, for example `nohead --json records list posts`. The [overview](/cli/overview#configuration) has how they combine with environment variables, `nohead.json` and saved keys.

| Option | |
|---|---|
| `-V, --version` | Output the version number. |
| `--json` | Print machine-readable JSON on stdout. |
| `--project <id>` | Project to work in, and so its saved API key (default: $NOHEAD_PROJECT, then the nearest nohead.json, then the only saved key) |
| `--note <text>` | Reason for the change, kept in the history of records and the schema. |
| `--idempotency-key <key>` | Makes retrying a mutation safe: the same key and request return the first result. |
