Every command takes these, for example `nohead --json records list posts`. The [overview](/cli/overview#configuration) has how they combine with environment variables and saved profiles.

| Option | |
|---|---|
| `-V, --version` | Output the version number. |
| `--json` | Print machine-readable JSON on stdout. |
| `--api-url <url>` | API base URL (default: $NOHEAD_API_URL) |
| `--project <id>` | Project ID (default: $NOHEAD_PROJECT, or the API key's project) |
| `--profile <name>` | Saved credentials to use (default: $NOHEAD_PROFILE or default) |
| `--note <text>` | Reason for the change, kept in the history of records and the schema. |
| `--idempotency-key <key>` | Makes retrying a mutation safe: the same key and request return the first result. |
