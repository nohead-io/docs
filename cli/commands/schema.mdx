## `nohead schema pull`

Write the project's schema to a file (default nohead.schema.yaml; - for stdout)

```bash
nohead schema pull [options]
```

| Option | |
|---|---|
| `--output <file>` | Where to write it. Default: `"nohead.schema.yaml"`. |

## `nohead schema diff`

Show what push would change.

```bash
nohead schema diff [options] [file]
```

| Argument | |
|---|---|
| `[file]` | Schema file. |

| Option | |
|---|---|
| `--exit-code` | Exit 1 when there are changes. |
| `--no-preview` | Skip dry runs of field migrations. |

## `nohead schema push`

Change the project's schema to match the file (never deletes anything)

```bash
nohead schema push [options] [file]
```

| Argument | |
|---|---|
| `[file]` | Schema file. |

| Option | |
|---|---|
| `--yes` | Apply the changes (without it, push only shows them) |
| `--allow-migrations` | Allow type and multiple changes, which rewrite record values. |
| `--clear-invalid` | In migrations, clear values that cannot be converted. |
