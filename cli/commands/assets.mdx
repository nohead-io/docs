## `nohead assets list`

List assets, newest first.

```bash
nohead assets list [options]
```

| Option | |
|---|---|
| `--deleted` | List deleted assets instead. |
| `--search <words>` | Only assets whose filename or alt text has every word. |
| `--kind <kinds>` | Only assets of a kind, or several: image, video, audio, document, other (comma-separated) |
| `--limit <n>` | Page size (1-100, default 100) |
| `--cursor <cursor>` | Continue from a previous page's next_cursor. |
| `--all` | Follow cursors and return every asset. |

## `nohead assets upload`

Upload files; prints their asset IDs for use in records.

```bash

```

| Argument | |
|---|---|
| `<files...>` | Files to upload. |

| Option | |
|---|---|
| `--content-type <type>` | Override the type guessed from the extension. |

## `nohead assets update`

Rename an asset or set its alt text.

```bash
nohead assets update [options] <id>
```

| Argument | |
|---|---|
| `<id>` | Asset ID (ast_...) |

| Option | |
|---|---|
| `--filename <name>` | New filename (downloads use it) |
| `--alt <text>` | Alt text: what the image shows, the default wherever it is used ("" clears it) |

## `nohead assets url`

Print an image's URL, resized, cropped or converted.

```bash
nohead assets url [options] <id>
```

| Argument | |
|---|---|
| `<id>` | Asset ID (ast_...) |

| Option | |
|---|---|
| `--width <px>` | Width in pixels. |
| `--height <px>` | Height in pixels. |
| `--fit <fit>` | How the image fills width and height. One of `contain`, `cover`, `fill`. Default: `"contain"`. |
| `--format <format>` | The image format. One of `original`, `webp`, `avif`, `jpeg`, `png`. Default: `"original"`. |
| `--quality <n>` | 1-100. |
