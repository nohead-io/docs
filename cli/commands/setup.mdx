Every command also takes the [global options](/cli/commands/global-options), such as `--json`.

## `nohead login`

Sign in with the browser and save an API key for the project you choose; a key piped in is checked and saved as it is (echo $KEY \| nohead login)

```bash
nohead login [options]
```

## `nohead logout`

Forget the API key saved for the project in use (the key itself stays valid; revoke it in the web app)

```bash
nohead logout [options]
```

## `nohead link`

Use a project in this folder and the folders below it: writes nohead.json, which holds no secret, so it can be committed.

```bash
nohead link [options] <project>
```

| Argument | |
|---|---|
| `<project>` | Project ID (prj_...) |

## `nohead whoami`

Show the credentials in use (API key, project and where it came from, scopes)

```bash
nohead whoami [options]
```

## `nohead health`

Check that the API is reachable and healthy.

```bash
nohead health [options]
```

## `nohead flags`

Show feature flags as evaluated for your API key's project.

```bash
nohead flags [options]
```
