Every command also takes the [global options](/cli/commands/global-options), such as `--json`.

## `nohead login`

Save an API key for later commands; reads the key from stdin (echo $KEY \| nohead login)

```bash
nohead login [options]
```

## `nohead logout`

Forget a saved API key (the key itself stays valid; revoke it in the web app)

```bash
nohead logout [options]
```

## `nohead whoami`

Show the credentials in use (API key, project, scopes)

```bash
nohead whoami [options]
```

## `nohead health`

Check that the API is reachable and healthy.

```bash
nohead health [options]
```

## `nohead flags`

Show feature flags as evaluated for your API key's project.

```bash
nohead flags [options]
```
